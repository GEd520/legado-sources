# 验收清单（5 分钟走完）

> 环境：Android 手机 + 阅读 App（Legado）。电脑上要先能打开 `github.com`。

## 0. 一次性准备

订阅源地址（三选一，能打开哪个用哪个）：

```
https://raw.githubusercontent.com/GEd520/legado-sources/main/dist/all.json
https://ghproxy.net/https://raw.githubusercontent.com/GEd520/legado-sources/main/dist/all.json
https://gh-proxy.com/https://raw.githubusercontent.com/GEd520/legado-sources/main/dist/all.json
```

**在手机上先测一下哪个能开**：浏览器打开上面任一地址，能看到一大段
`[{"bookSourceName":...` 开头的文字就算通。打不开就换下一个。

## 1. 导入书源

阅读 → 我的 → 书源管理 → 右上角 ⋮ → 导入书源 → 订阅源导入 → 粘贴地址 → 确定。

- [ ] 列表里出现 **🌸 爱丽丝🔞◎辞晨◎** 和 **🌐绅士漫画◎辞晨◎** 两个源
- [ ] 两个源默认是**关闭**状态（原作者就是这么设的），手动打开开关

## 2. 授权（只有爱丽丝需要）

1. 打开爱丽丝源 → 右上角 ⋮ → 编辑 → 找到「登录」相关入口（源里叫 `getInfo('源作者：')`）
2. 在**登录界面**的账号框里填：`辞晨`
   （源的说明里也写了：`防倒卖，请在登录UI界面输入作者名：辞晨`）
3. 密钥框填：`` `MjAyNjExMDE=` ``（这是当年当月有效的授权码；过期就用下面算法算）

> 授权码算法：年份 4 位 + (月份+1) 补两位 + `01`，再 Base64。
> 例：2026 年 10 月 → `2026` + `11` + `01` = `20261101` → Base64 = `MjAyNjExMDE=`

- [ ] 填完能进书源详情页，不报「校验失败！请联系源作者」

## 3. 关键验收：门禁是否真的在挡

**这一步是整套方案的核心，一定要测。**

用另一个手机 / 或把爱丽丝源复制一份改个名（改 `bookSourceUrl` 即可）：

- [ ] 没填授权码时，发现页显示报错（**不是**空白，也不是显示内容）
- [ ] 报错文字里带「门禁」「授权」之类字样

如果没填授权码也能正常看，说明**门禁没生效**，告诉我，我改。

## 4. 热更新验收（C 档）

这一步证明「以后更新不用重发订阅源」。

1. 电脑上改 `sources/libs/lib-ailisi.js`（随便加一行 `java.log('v2')` 也行）
2. 跑 `node tools/gate-release.mjs ailisi`
3. 手机上：书源详情页下拉刷新（或杀掉 App 重进）

- [ ] 能看到改动生效，**没有重新导入书源**

## 5. 控制台（可选）

订阅源里还有一条 **🌐 书源控制台**，添加后能看到：
书源版本、门禁状态、刷新按钮。

## 6. 失效自查（出问题时看这里）

| 现象 | 原因 | 处理 |
|---|---|---|
| 订阅源导入失败 | GitHub 被墙 / 加速链接失效 | 换第 0 步的另一个地址 |
| 「门禁不可达」 | CF 边缘连不上 | 换 Wi-Fi / 移动网络；或等 5 分钟重试 |
| 「校验失败！请联系源作者」 | 授权码过期 | 用第 2 步的公式算当月新码 |
| 发现页空白 | 书源被关了 | 书源管理里确认开关是开的 |
| 更新不生效 | 缓存还没过期 | 等 5 分钟，或杀掉 App 重进 |
